# MetaSupply

Prove when a document existed. MetaSupply records a tamper-proof SHA-256 fingerprint of a file on the Internet Computer (ICP) blockchain, together with its title, author and the blockchain's date and time. When the document changes, the new file is registered as a new version linked to the previous one. Anyone can check a file, or paste its fingerprint, to see when it was registered, by whom, and every version before and after it.

- **Records can't be edited or deleted.** The canister has no methods for either.
- **First come, first recorded.** A given file can only be registered once.
- **Only the owner adds versions.** Only the account that registered a document can register new versions of it, and only on top of the latest version, so the history is a single line.
- **Files stay private.** Only the fingerprint is stored; the file never leaves the user's computer.

## How it fits together

| Part | Where | What it does |
|---|---|---|
| Backend canister (`src/metasupply_backend`) | ICP mainnet | Stores records in stable memory (survives upgrades). Rust. |
| Website (`src/metasupply_frontend`) | GitHub Pages or an ICP asset canister | Hashes files in the browser, registers and verifies them. React + Vite + Tailwind. |
| Candid bindings (`src/declarations/metasupply_backend`) | In the repo | Typed interface between the two, generated by `dfx generate`. |

Logging in uses Internet Identity and is only needed to register. Verifying is public.

### Canister interface

```candid
register : (RegisterArgs) -> (variant { Ok : Document; Err : RegisterError });
get_document : (text) -> (opt Document) query;          // by SHA-256 hash
get_history : (text) -> (vec Document) query;           // every version, oldest first
get_my_documents : () -> (vec Document) query;
total_documents : () -> (nat64) query;
```

## Develop locally

Requires [dfx](https://internetcomputer.org/docs/building-apps/getting-started/install) (on Windows, use WSL), Rust with the `wasm32-unknown-unknown` target, and Node 18+.

```bash
npm install
cargo test -p metasupply_backend    # backend unit tests, including the Candid interface check
dfx start --clean --background
dfx deploy
npm start                           # http://localhost:8080
```

After changing the backend's public functions, regenerate the bindings:

```bash
cargo test -p metasupply_backend    # prints the new interface if metasupply_backend.did is out of date
dfx generate metasupply_backend
```

## Deploy the backend to the IC mainnet

You need a dfx identity and cycles (a few trillion cycles, roughly a few US dollars; see [Cycles](https://internetcomputer.org/docs/building-apps/getting-started/tokens-and-cycles)).

```bash
dfx identity new metasupply         # choose a password and store the seed phrase safely
dfx identity use metasupply
dfx ledger account-id --network ic  # send ICP here, then:
dfx cycles convert --amount 0.5 --network ic
dfx deploy --network ic metasupply_backend
dfx canister --network ic id metasupply_backend
```

Commit the `canister_ids.json` that dfx creates, so later deploys upgrade the same canister.

### Optional: make the canister fully immutable

The canister's controller (you) can still upgrade its code. Once you're confident in it, you can remove your identity as controller ("blackholing"), so nobody, including you, can ever change it. Follow the official ICP documentation on canister controllers when you do this. It can't be undone: you won't be able to fix bugs afterwards. Anyone can still top it up with cycles.

## Deploy the website to GitHub Pages

`.github/workflows/deploy.yml` tests and builds the backend, builds the website, and publishes it to the `gh-pages` branch on every push to `deployment`.

1. In the repo, go to **Settings → Secrets and variables → Actions → Variables** and add `CANISTER_ID_METASUPPLY_BACKEND` with the mainnet canister ID.
2. In **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `gh-pages`, folder `/ (root)`.
3. Push to `deployment`, or re-run the workflow. The site appears at `https://<user>.github.io/Metasupply/`.
